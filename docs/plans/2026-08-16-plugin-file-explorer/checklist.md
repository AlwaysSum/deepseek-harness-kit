# plugin-file-explorer 验收清单（checklist）

> 用法：每项完成后勾选。全部勾选 = 功能验收通过。
> 环境：dsh 服务已启动且已启用 `@dsh-kit/plugin-file-explorer`（桌面端「设置 → 内置插件」或 `install.mjs`）。

## A. 侧边栏双 Tab（FR1 / FR4）

- [ ] A1 左侧工作区顶部显示「会话」「文件」两个 Tab，默认停在「会话」。
- [ ] A2 切到「文件」：展示当前会话工作区文件树（目录优先、字母序、跳过 `.git` 与 `node_modules`）。
- [ ] A3 「会话」列表按时间倒序，点击切换当前会话；当前会话行高亮。
- [ ] A4 切换会话后，文件树刷新为新会话工作区；已打开的文件 Tab 全部关闭，回到纯「对话」。

## B. 文件树操作（FR2）

- [ ] B1 目录可点击展开/收起，展开状态与缩进正确。
- [ ] B2 新建文件：在根或某目录下输入名称创建；打开后自动出现在树中；重名/非法名（空、含 `/\`）有错误提示且不创建。
- [ ] B3 新建文件夹：同上，创建后立即显示为目录。
- [ ] B4 重命名：文件与目录均可；重名目标报错；改名后若该文件正被打开，编辑器 Tab 标题同步更新。
- [ ] B5 删除：文件直接删；目录弹二次确认后递归删；删除后若文件正被打开，对应 Tab 自动关闭。
- [ ] B6 刷新按钮：树重新拉取，外部改动可见。
- [ ] B7 全部展开 / 全部收起按钮生效。
- [ ] B8 操作入口可达：树根工具栏 + 树行 hover 操作按钮；操作失败有可见提示。

## C. 中间多 Tab 编辑器（FR3）

- [ ] C1 点击文件 → 中间标签环出现「对话 | 文件名」；重复点击同一文件不产生重复 Tab，仅激活已有 Tab。
- [ ] C2 初始/关闭全部文件后，标签环只剩「对话」；「对话」Tab 无关闭入口（不可关闭）。
- [ ] C3 编辑器加载文件内容；大文件或读取失败时显示错误并可重试。
- [ ] C4 修改内容后编辑器 chrome 显示脏标记（`●` / 「未保存」），保存后消失。
- [ ] C5 保存（按钮或 Ctrl+S）：成功提示「已保存」；失败保留脏标记并提示原因。
- [ ] C6 关闭（chrome 按钮或 Ctrl+W）：无修改直接关；有修改弹「是否保存/放弃/取消」确认。
- [ ] C7 关闭后标签环自动回落「对话」（active 文件被关时）。
- [ ] C8 编辑体验：Tab 键插入 4 空格缩进；Ctrl+Z/Y 撤销重做；行号 gutter 随滚动对齐。
- [ ] C9 编辑器 chrome 位于内容区顶部（文件名 + 脏标记 + 保存 + 关闭），不遮挡标签环。
- [ ] C10 json 文件打开为专门编辑器：输入非法时实时提示错误位置；「格式化」/「压缩」按钮生效；JSON 不合法时点保存被阻止并提示。
- [ ] C11 md 文件打开为左编辑右预览分屏：标题/列表/引用/代码块/行内粗斜体/链接渲染正确，编辑实时刷新预览。
- [ ] C12 html 文件打开为左编辑右预览分屏：编辑后 300ms 内预览自动刷新，预览 iframe 允许脚本；Ctrl+S / Ctrl+W 在 md/html 编辑区同样生效。

## D. 非文本文件（FR5，可选）

- [ ] D1 图片扩展名（png/jpg/jpeg/gif/webp/svg，≤2MB）以只读预览打开，Tab 不可编辑。
- [ ] D2 其他二进制文件提示「二进制文件，不支持编辑」，只读或拒绝打开。

## E. 稳定性与安全

- [ ] E1 打开→编辑→保存→关闭循环 20 次无重复 Tab、无泄漏报错（控制台无插件异常）。
- [ ] E2 快速点击不同文件（连续打开/关闭）不出现标签环错乱或白屏。
- [ ] E3 host 路由只接受 127.0.0.1/localhost 来源；越权路径（`../` 逃逸）返回 `invalid path`。
- [ ] E4 插件卸载（停用）后：影子覆盖恢复默认会话浏览区、文件 Tab 全部消失、无残留事件监听报错。
- [ ] E5 会话内切换/删除会话不报错，文件树显示「当前无活动会话」或空态。
- [ ] E6 中英文界面文案正确（词典注册到 `file-explorer` NS，无裸字符串遗漏）。
